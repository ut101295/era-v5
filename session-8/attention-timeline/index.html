The Evolution of Attention

Every mechanism from Session 8, in the order it was actually launched — each one an answer to the bill the previous one left behind.

Dates verified against the original paper / release (see sources on each card and in the README). Built for ERA V5 · Session 8.

Vanilla attention was not wrong — it was expensive. Everything after it is somebody looking at that bill and trying to pay less of one line on it: the compute (comparing every token with every other), the memory (the KV cache you must keep), or the length (how far the position scheme still works). Laid out by date instead of by family, you can watch the field change its mind about which bill hurts most. Use the filters to isolate one thread.

What the timeline shows (that a list can't)

Sorted by date, the mechanisms stop looking like a menu and start looking like an argument the field is having with itself. Four things jump out:

  1. It oscillates, it doesn't progress. First it chases exactness while cutting compute (Sparse 2019, top-k 2019, sliding window 2020). Then it wants memory back (MQA 2019 → GQA 2023 → MLA 2024). Then it wants length (RoPE 2021, ALiBi 2021, NTK 2023, YaRN 2023, sinks 2023). Then it wants memory back again, this time by throwing out the quadratic core entirely (linear 2020, delta 2021, DeltaNet 2024, Gated DeltaNet 2024). The same worry returns in a new costume every couple of years.
  2. The two 2019 papers are the whole fork. MQA (cut memory) and Sparse Transformers (cut compute) appear months apart and every later branch descends from one or the other. The split that organises the entire field is visible in a single year.
  3. Position encoding is a 2017 decision the field never stopped paying for. Sinusoidal → RoPE → ALiBi → NTK → YaRN → DroPE is one unbroken eight-year thread of patching the same original choice, ending (2025) with a paper arguing you should drop positional embeddings after training — i.e. that the fix is to undo the 2017 move.
  4. 2024–25 is convergence, not divergence. MLA, NSA and Gated DeltaNet each combine earlier threads (compression + sparsity + gated recurrence) rather than inventing a new axis. That's what a maturing field looks like — and it predicts the next step is a hybrid that pays all three bills at once.

The chronology is the point: you cannot see an oscillation from an alphabetised list, only from a date axis.

Sources. Every date is the first public release — arXiv v1 submission date, or the community post for NTK-aware scaling. Full citation list in the repo README. Known trap: DroPE (Sakana AI, "dropping positional embeddings", Dec 2025) is a different paper from DRoPE (directional RoPE for driving agents, Mar 2025) — this timeline uses the former.
